## 動機

[docs/12_音楽的整合.md](../../docs/12_音楽的整合.md) の §二「MUSUBI 音楽状態」を最小実装する。
これで祭文側から **共通 key / mode / bpm / register** を打てば、各依代がそれぞれの方言で同じ祈りを唱える系の土台が立つ。

12_ の §十一 によれば M5 は **最小**で良い：
- 内部状態 + setParam 受容
- 各依代の最小 `applyMusic({key, mode})` 翻訳
- tempoRatio は **1 固定**、voice-led / harmony / kagome 動的 customScale / register は **後段（M6-M8）**

### 2. field の音楽状態 ─ [field/field.js](../../field/field.js)

`state` に `music` 内部状態を追加：

```js
state.music = {
  key: 0,           // 既定 C
  mode: "凪",        // 既定
  bpm: 60,          // 既定
  register: 0,
  bar: 0,           // derived（M5 では未使用）
  beat: 0,          // derived（M5 では未使用）
};
```

M4 で追加された MUSUBI setParam adapter（`applyMusubiSetParam` 等）に、新規 param 名 4 種を受ける分岐を追加：

| param | 値 | 処理 |
|---|---|---|
| `music.key` | "C" / "F#" / 0..11 | `parseKey` で正規化、state.music.key 更新、`applyMusicAll()` 起動 |
| `music.mode` | 12 種 enum 文字列 | state.music.mode 更新、`applyMusicAll()` |
| `music.bpm` | 数 | state.music.bpm 更新、`applyMusicAll()` |
| `music.register` | -1..+1 | state.music.register 更新、`applyMusicAll()` |

`applyMusicAll()` は接続中の各依代に対して、その依代のアダプタを呼び `sendRelay` を吐く。

不明な name（typo 等）は `pushKotodama` に warn を出して無視（既存方針通り）。

### 3. NAGARE InstrumentMap に `musical` セクション追加

[field/nagare.js](../../field/nagare.js) の `InstrumentMap` 各依代に `musical` を追加。書式：

```js
"ocean": {
  抜き差し: { ... },         // 既存
  律動: { ... },              // 既存
  転調: { ... },              // 既存
  musical: {
    register: "bass",
    accept: ["key", "mode"],   // M5 では bpm/register は無視
    apply: function (id, music) {
      // music = { key: 0..11, mode: "凪"|"琉球"|..., bpm, register }
      // 返り値: relay 配列（cmd: setParam | ramp）
      // M5 では setParam の即時切替で良い（ramp は M6）
      const nativeScale = OCEAN_SCALE_MAP[music.mode] || "ペンタトニック";
      const nativeRootHz = nearestOceanRoot(music.key);
      return [
        { target: id, cmd: "setParam", name: "scale", value: nativeScale },
        { target: id, cmd: "setParam", name: "root", value: nativeRootHz }
      ];
    }
  }
}
```

各依代の native マッピング表は [docs/12_音楽的整合.md](../../docs/12_音楽的整合.md) §三 「依代別 native マッピング」を参照。**正確に転記すること** ─ 表が正典。

### 4. cell-noise を InstrumentMap に追加（接続待ちでも）

cell-noise は場接続待ちだが、InstrumentMap には**今のうちに**枠を作っておく。実体接続後すぐ動くように：

```js
"cell-noise": {
  抜き差し: {
    voices: ["sineMix", "pulseMix", "noiseMix"],
    floor: 0.10,
    apply: function (id, voice, value) {
      return { target: id, cmd: "setParam", name: voice, value: +(value).toFixed(4) };
    }
  },
  律動: {
    apply: function (id, value) {
      return [
        { target: id, cmd: "setParam", name: "pulseRate", value: +(0.5 + value * 16).toFixed(3) },
        { target: id, cmd: "setParam", name: "burstDensity", value: +(0.1 + value * 0.7).toFixed(4) }
      ];
    }
  },
  転調: {
    apply: function (id, value) {
      return { target: id, cmd: "setParam", name: "pitchBase", value: Math.round(80 + value * 540) };
    }
  },
  musical: {
    register: "hi",
    accept: ["key", "mode"],
    apply: function (id, music) {
      // cell-noise は連続 Hz のみ。mode は (mode === "凪") の時だけ極小モード化
      const baseHz = keyToHz(music.key, 4); // C4 基準 octave
      const relays = [
        { target: id, cmd: "setParam", name: "pitchBase", value: baseHz }
      ];
      if (music.mode === "凪") {
        relays.push({ target: id, cmd: "setParam", name: "pulseRate", value: 0.5 });
        relays.push({ target: id, cmd: "setParam", name: "burstDensity", value: 0.1 });
      }
      return relays;
    }
  }
}
```

`makeDefaultInstrumentConfig` にも `cell-noise: { 抜き差し: true, 律動: true, 転調: true }` を追加。

### 5. 補助関数

field か nagare に共通の小関数を：

```js
function keyToHz(key, octave) {
  // key: 0..11, octave: 4 が中央 (C4 = 261.63)
  const midi = 12 * (octave + 1) + key;  // C4 → midi 60
  return 440 * Math.pow(2, (midi - 69) / 12);
}

function clampToNative(key, nativeIndices) {
  let best = nativeIndices[0], bestDist = 12;
  for (const n of nativeIndices) {
    const d = Math.min((key - n + 12) % 12, (n - key + 12) % 12);
    if (d < bestDist) { best = n; bestDist = d; }
  }
  return best;
}

function nearestOceanRoot(key) {
  // OCEAN_ROOTS = [55, 65, 73, 82, 87, 98, 110, 123, 138]
  // 各 Hz が表す MIDI 半音を計算し、key (mod 12) との最近接を返す
  const oceanMidi = OCEAN_ROOTS.map(hz => Math.round(69 + 12 * Math.log2(hz / 440)));
  // ...
}
```

## 合格条件

1. 祭文に `"音楽":{"key":"D","mode":"琉球","bpm":80}` を入れて場に招くと、ocean の root と scale が D・琉球相当に切り替わる（kagome も同様、planarian も同様、geometry も同様）
2. 祭文の祭次に `{ "時": 60, "target": "MUSUBI", "command": "setParam", "param": "music.mode", "value": "マカーム" }` を入れると、その時刻に全依代が一斉に native scale を切替
3. 接続済 8 依代全てに `musical.apply` が呼ばれ、scale を持つ 4 依代（ocean / kagome / planarian / geometry）は scale を更新、scale を持たない 4 依代（stone / mycorrhiza / particle / cell）は無視（または mode=凪 時のみ極小モード）
4. cell-noise が場に接続された瞬間、InstrumentMap に既にエントリがあるので即座に同様に動く
5. 既存の境地 setParam（M4 で実装）と共存（境地と音楽は独立に切り替えられる）
6. 祭文の `音楽` block が無い場合、現状と変わらず動く（後方互換）

## 触ってはいけないもの

- 既存の境地 (NAGARE.setMode)・seed・scale.fn 等の M4 設定
- 既存の祭次・判示・relay 経路
- 依代側 [shared/el-systema-control.js](../../shared/el-systema-control.js)
- M6 以降の機能：tempoRatio・voice-led・kagome 動的 customScale・harmony 信号・register zone の octave bias

## 注意

- `applyMusicAll` は冪等にする（同じ music で何度呼んでも同じ relay を出して可）
- 不明 mode は warn して無視、`explainLiturgy` で事前に弾くので runtime には来ないが防御的に
- kagome は M5 では native の scalePreset を切り替えるだけで良い（key 別の customScale 動的生成は M7）
- planarian / geometry の root clamp は §四「Universal key と clamp」の通り。**clamp ずれは方言として歓迎**（ログ警告等は出さない）
- M5 完了時点では音楽的にまだ「揃わない」場面が多いが、それで良い。M6 (tempoRatio + ramp) と M7 (kagome dynamic) が乗ると本格化する
