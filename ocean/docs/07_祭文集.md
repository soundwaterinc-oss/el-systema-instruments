# 07 祭文集

巫の場で唱える御願詞（祭文）の集。各巻は単独で奉れる完結した儀。
祭文の正式形は [shared/el-systema-shapes.js](../shared/el-systema-shapes.js) の schema による JSON。本文書は綴び（あらすじ）と注釈を記す。

---

## 第一巻 ─ 潮の起こりと石の還り 序

実体：[liturgy.stone-ocean.json](../liturgy.stone-ocean.json)
楽器：**ocean**（依代）、**stone-beats**（依代）
所要：180 秒（3 分）
担当：CC 起草 / Codex 上演

### 綴び

> 凪の海から始まる。黒潮が深まり、砂礫が混じり始める。
> さざ波になると玄武岩が拍を取り、花崗岩が応える。
> 雨嵐に至り雷が鳴り、磁石が共鳴する。
> 還りで、石たちは順に沈黙し、海は凪に戻る。
> 神は送られ、場は空に戻る。

### 祭次の輪郭

```
0:00  ─  ocean を凪・黒潮で立てる
0:01  ─  ocean 演奏開始
0:15  ─  潮流の深さを 30 → 70 へゆっくり持ち上げる（20 秒）
0:20  ─  stone-beats を砂礫だけ、1/f 律動、低音量で立てる
0:22  ─  stone-beats 演奏開始
0:40  ─  天候をさざ波に変える
1:00  ─  玄武岩を呼ぶ（voice.玄武岩.on = true）
1:15  ─  雨を 0 → 30 まで持ち上げる（15 秒）
1:30  ─  天候を荒波に
1:35  ─  花崗岩を呼ぶ
1:40  ─  雷を 0 → 60 まで持ち上げる（30 秒）
2:10  ─  天候を雨嵐に（雷雨）
2:20  ─  磁石を呼ぶ
2:40  ─  雷を 60 → 0 へ落とす（15 秒）。stone-beats も同時にフェードアウト（20 秒）
2:50  ─  天候を凪に戻す
2:58  ─  両依代を止める
```

### 判示（応答）

| 名 | 条件 | 為 | 一度／冷却 |
|---|---|---|---|
| 海が満ちたら、石が応える | `presence:ocean > 0.4`、4 秒持続 | stone-beats の玄武岩の密度を 100 にする | 冷却 30 秒 |
| 石が黙ったら、海が和らぐ | `silence:stone-beats > 8` 秒 | ocean の天候をさざ波に戻す | 冷却 60 秒 |
| 雷が鳴ると、磁石が共鳴 | `presence:ocean > 0.7`、2 秒持続 | stone-beats の磁石の ping 送りを 80 まで上げ、密度を 100 に | 冷却 15 秒 |
| 雨が止んだら、石は沈黙へ | `silence:ocean > 5` 秒 | stone-beats の音量を 30 へ ramp（10 秒） | 一度 |

### 揺らぎ（招の時に焼かれる）

各祭次の `揺` 値で時間方向の散らしを与える。同じ祭文でも招ごとに少し違う流れになる。

### 終わり方

- 178 秒目で `stop` が両依代に飛ぶ
- ヌジファ（quench）が自動で起きる
- 言上には招から終わりまでの全往来が残る

## 第二巻 ─ 九の輪（九声の一日）

実体：[liturgy.nine-voices.json](../liturgy.nine-voices.json)
楽器：**stone-beats / ocean / geometry-scanner / particle-noise / planarian-drone / kagome-sound / mycorrhiza-beat / moss-reservoir / cell-noise**（9 依代）
所要：600 秒（10 分）
担当：CC 起草 / Codex 上演（M4 で自動化）

> cell-noise はまだ場に上がっていない（[REGISTRY.md](../REGISTRY.md) 接続待ち）。接続が済むまでは巫が `祭が読めません` と返すため、招くには cell-noise の場参加を待つ。

### 綴び

> 九つの依代が一日の循環を奏でる。
> 暁の凪に苔と平板の藻が目覚め、朝の流れに海と籠目が応える。
> 真昼の動きに菌糸と石が拍を取り、夕の嵐に粒子と幾何が交錯する。
> 夜の整えに細胞の二値が現れて精密が刻まれ、深夜の無に長い沈黙がバーストを抱く。
> 還りで全声は順に沈み、御嶽は空に戻る。

### 章構成と境地遷移

| 時刻 | 章 | 境地 | 主役の依代 | 残り |
|---|---|---|---|---|
| 0:00-1:00 | **暁** | 凪 | planarian-drone / moss-reservoir | 全 off |
| 1:00-2:30 | **朝** | 流 | + ocean / kagome-sound | 打物・粒子・幾何・cell off |
| 2:30-4:30 | **昼** | 動 | + stone-beats / mycorrhiza-beat | 粒子・幾何・cell off |
| 4:30-6:30 | **夕** | 嵐 | + particle-noise / geometry-scanner、ocean 雨嵐 | cell off |
| 6:30-8:00 | **夜** | 整 | + cell-noise（Ikeda 様の二値の主役） | 9 全 on |
| 8:00-9:30 | **深夜** | 無 | 全声 fading、Lévy バースト | ─ |
| 9:30-10:00 | **還り** | 凪 → ヌジファ | cell-noise を先頭に順に消える | ─ |

各章の**内部展開は NAGARE 任せ**（自律的に抜き差し・律動・転調）。祭次は「scene setting」のみを書く。

### 祭次の主要点

1. 各章冒頭で `target: "MUSUBI"` の setParam で `境地` を切替
2. 各依代の `play` / `stop` を章境界で送る
3. 境地切替直後に各依代へ `loadPreset` で章固有の音色を上書き
4. 還りで全 `master` を ramp で 0 へ

### 判示（応答）

| 名 | 条件 | 為 | 冷却 |
|---|---|---|---|
| 海が満ちたら、菌糸が応える | `presence:ocean > 0.5`、3 秒持続 | mycorrhiza-beat の bpm を 2 倍 ramp（10 秒） | 60 |
| 雷が落ちたら、磁石が共鳴 | `presence:ocean > 0.85`、1 秒持続 | stone-beats `voice.磁石.ping` を 90 へ | 15 |
| 全声が沈黙へ近づいたら、ドローンを伸ばす | （要 NAGARE で複合判定） | planarian-drone `sustain` を倍に | 90 |
| ドローンが沈黙したら、苔が応える | `silence:planarian-drone > 8` | moss-reservoir `master` を ramp で増 | 120 |
| 籠目が満ちたら、石灰岩が転調 | `presence:kagome-sound > 0.6`、4 秒持続 | stone-beats `voice.石灰岩.on` を 1 | 45 |

### NAGARE の seed

招の時に `(Date.now() % 100000) / 100000` で焼く。
**再現したい時は `seed: 0.42` を祭文の root に置く**（fixed seed）。

### Codex 実装済み（M4）

祭文から **MUSUBI/NAGARE を直接操作**できる：

- `target: "MUSUBI"`（または `"nagare"`）が valid target
- `setParam("境地", "流")` → `NAGARE.setMode("流")`
- `setParam("seed", 0.42)` → NAGARE seed の上書き
- `setParam("scale.拍.fn", "logistic")` → `NAGARE.setScaleConfig`
- `setParam("instrument.<id>.<role>", true)` → `NAGARE.setInstrumentRole`

これで第二巻は**完全自動**で 10 分演奏できる。

## 祭文を書く時の注意

1. **duration は正確に** ─ 祭次の最後の時刻 + 余裕（最終 ramp が終わる時間）以上にする
2. **target の id は実在を確認** ─ 場に立っていない id を書くと、巫が「祭が読めません」と返す
3. **応答の `信号` は `<種>:<id>` 形式** ─ presence/silence/low/high/density 等、kehai 由来のもの
4. **`揺` は 0 でも良い** ─ 厳密な時刻を要求する所では揺を 0 に
5. **`冷却` は秒** ─ 連続発火を抑える
6. **`preset` の中身は target 依代が受け取れる形** ─ [docs/09_接続契約.md](09_接続契約.md) §六の各楽器パラメータを参照
