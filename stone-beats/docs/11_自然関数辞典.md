# 11 自然関数辞典

NAGARE が作曲源として使う関数の一覧。すべて `nextValue(state) -> [0, 1]` の共通 API。

各関数は state を持ち越して呼ばれる。`seed` は招の時に焼かれた値。

---

## 1/f 揺らぎ（pink noise / Voss-McCartney）

**性格**：自然に頻出する不規則。中央寄り、稀に極端。森林・河川・鼓動・脳波。

```js
function pink_init(seed) {
  return { levels: Array.from({length:7}, () => rand(seed)), beat: 0 };
}
function pink_next(state) {
  state.beat++;
  for (let k = 1; k < state.levels.length; k++) {
    if (state.beat % (1 << k) === 0) state.levels[k] = Math.random();
  }
  state.levels[0] = Math.random();
  return state.levels.reduce((a,b) => a+b, 0) / state.levels.length;
}
```

**適合**：抜き差し・密度の全般。「もっとも自然な」ふるまい。

---

## ロジスティック写像（logistic map）

**性格**：r=3.95 で完全カオス。急な遷移、突発的な静寂と爆発。

```js
function log_init(seed, r=3.95) { return { x: 0.4 + 0.1*seed, r }; }
function log_next(state) {
  state.x = state.r * state.x * (1 - state.x);
  return state.x;
}
```

**適合**：律動の突発切替・破調・サンプリング点の選択。

---

## Lorenz 引力子

**性格**：σ=10, ρ=28, β=8/3 の三次元カオス。二葉の間を蝶のように往来。

```js
function lor_init(seed) { return { x: 0.1+seed*0.1, y: 0, z: 0 }; }
function lor_next(state, dt=0.015) {
  const σ=10, ρ=28, β=8/3;
  const dx = σ*(state.y - state.x);
  const dy = state.x*(ρ - state.z) - state.y;
  const dz = state.x*state.y - β*state.z;
  state.x += dx*dt; state.y += dy*dt; state.z += dz*dt;
  return Math.max(0, Math.min(1, (state.x + 20) / 40));
}
```

**適合**：二極の周期的訪問（例：明と暗、密と疎）。Lorenz は二葉の引力子なので二状態を行き来する性質。

---

## 黄金角ステップ（phyllotaxis）

**性格**：n·φ mod 1（φ = (1+√5)/2）。準周期、決して反復せず均等に巡る。植物の葉序。

```js
function gold_init(seed) { return { n: Math.floor(seed * 100) }; }
function gold_next(state) {
  const φ = (1 + Math.sqrt(5)) / 2;
  state.n++;
  return (state.n * φ) % 1;
}
```

**適合**：転調・色の循環。同じ位置に二度戻らないので章単位の進行に最適。

---

## フィボナッチ間隔

**性格**：1, 1, 2, 3, 5, 8, 13, 21... 指数的に疎密が広がる。

```js
function fib_init(seed) { return { i: 0, fib: [1, 1] }; }
function fib_next(state) {
  while (state.fib.length < state.i + 3) {
    state.fib.push(state.fib[state.fib.length-1] + state.fib[state.fib.length-2]);
  }
  state.i++;
  // 正規化：fib[i] / fib[i+10] のような形でで [0,1] に
  return (state.fib[state.i] % 100) / 100;
}
```

**適合**：加速する展開（じわじわ盛り上がり）、間隔（hit の打ち時を疎→密に）。

---

## ブラウン運動（Brownian / random walk）

**性格**：直前値からの差分が小さい乱歩。なめらかな漂い。

```js
function brown_init(seed) { return { x: 0.5 + (seed - 0.5)*0.1 }; }
function brown_next(state, step=0.05) {
  state.x += (Math.random() - 0.5) * step;
  state.x = Math.max(0, Math.min(1, state.x));
  return state.x;
}
```

**適合**：節レベルの緩い移ろい。1/f より滑らか、より「漂う」感じ。

---

## 正弦合成（incommensurate sines）

**性格**：通約しない（無理数比の）正弦の和。決して反復しない波。

```js
function sin_init(seed) { return { t: seed * 100 }; }
function sin_next(state, dt=0.05) {
  state.t += dt;
  const a = Math.sin(state.t * Math.PI);
  const b = Math.sin(state.t * Math.E);     // π と e は無理数比
  const c = Math.sin(state.t * Math.sqrt(2));
  return (a + b + c + 3) / 6;  // 正規化
}
```

**適合**：うねりの重なり、ゆっくり気分が変わる場面。

---

## セルラーオートマトン（Rule 30 / Rule 110）

**性格**：二値の決定論的展開。単純なルールから複雑な模様。Wolfram の発見。

```js
function ca_init(seed, rule=30) {
  const width = 64;
  const cells = new Uint8Array(width);
  cells[Math.floor(width/2)] = 1;  // 中央だけ 1 から開始
  return { cells, rule };
}
function ca_next(state) {
  const w = state.cells.length;
  const next = new Uint8Array(w);
  for (let i = 0; i < w; i++) {
    const l = state.cells[(i - 1 + w) % w];
    const c = state.cells[i];
    const r = state.cells[(i + 1) % w];
    const idx = (l << 2) | (c << 1) | r;
    next[i] = (state.rule >> idx) & 1;
  }
  state.cells = next;
  // 中央セルの値を [0, 1] に
  return state.cells[Math.floor(w/2)] ? 1 : 0;
}
```

**適合**：Ikeda 様の二値グリッチ、密度の二値オン/オフ。Rule 30 はカオス、Rule 110 はチューリング完全。

---

## Lévy 飛翔（heavy-tailed jump）

**性格**：Pareto 分布、ほとんど小さなステップ、稀に長距離ジャンプ。捕食者の探索。

```js
function levy_init(seed, alpha=1.5) { return { phase: seed, alpha }; }
function levy_next(state) {
  const u = Math.max(0.001, Math.random());
  const step = 1 / Math.pow(u, 1 / state.alpha);
  state.phase = (state.phase + step * 0.05) % 1;
  return state.phase;
}
```

**適合**：稀なバースト、長い静寂と突然の発火。stone-beats の Lévy 律動と同じ系統。

---

## 共通 API

```js
// 関数名 → { init: (seed, ...opts) -> state, next: (state) -> [0, 1] }
const NATURAL = {
  "pink":     { init: pink_init,  next: pink_next },
  "logistic": { init: log_init,   next: log_next },
  "lorenz":   { init: lor_init,   next: lor_next },
  "gold":     { init: gold_init,  next: gold_next },
  "fib":      { init: fib_init,   next: fib_next },
  "brown":    { init: brown_init, next: brown_next },
  "sine":     { init: sin_init,   next: sin_next },
  "ca":       { init: ca_init,    next: ca_next },
  "levy":     { init: levy_init,  next: levy_next },
};
```

NAGARE は境地に応じてこれらを組み合わせる。seed は招の時に焼く（再現性）。
