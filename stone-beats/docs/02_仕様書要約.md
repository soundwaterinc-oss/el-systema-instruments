# 02 仕様書要約 ─ ユタ儀礼としての EL-SYSTEMA / MUSUBI

[01_語彙と所作と筋書き](../01_語彙と所作と筋書き.md) の正典に従う。本書はユタ（沖縄・奄美の女性霊媒）の語彙を引いて、既存語の原義と作法を厚くする。語は変えない。実装は語に従う。

## 名の階層

```
EL-SYSTEMA                 ─ 全体（楽器世界・記録・歴史）
└ MUSUBI                   ─ ceremonic に依代を繋ぐ系（本書の対象）
   ├ 御嶽（hub）
   ├ ユタ（field）
   ├ 葉 API（shared）
   ├ 御願詞（祭文）
   └ 依代（楽器）
```

**MUSUBI（結び）** は神道の「むすび」─ 万物を繋ぐ霊的な力 ─ から引いた。
動詞として動く：「stone-beats が MUSUBI に結ばれた」「結びを解く」「結びを通る」。
ユタ語彙ではないが、ユタ儀礼と神道の作法は同じ列島の知恵の重なりとして扱う。

## 一・既存語とユタの対応

ユタは神（カミ）と人の間で**判示（ハンジ）**を下し、**御願（ウガン）**を取り次ぐ。EL-SYSTEMA の語は既にユタ儀礼の構造に沿っている：

| 既存語 | ユタの語 | 役 |
|---|---|---|
| **場** | **御嶽（ウタキ）** | 神を招く聖所。ユタはここで籠る |
| **巫（ヲサ）** | **ユタ** | 神と人を媒する者。AI ではなく、人と装置の連結体 |
| **器** | **依代（ヨリシロ）** | 神が降りる依りどころ。楽器はそれぞれ別の神 |
| **祭文（ガイス）** | **御願詞（ウガングトゥ）** | 神に上げる詞。順序と揺らぎを持つ |
| **御題** | **御願（ウガン）** | 取り次ぎの一句。一つの依代に向ける |
| **応答** | **判示（ハンジ）** | 神からの返事。条件が満ちた時に下る |
| **神籠り（カミゴモリ）** | **神籠り** | ユタが御嶽で神と一つになる時間 |
| **気配（ケハイ）** | **マブイ** | 魂・存在感。生音から読まれる |
| **ハツイガコ** | **マブイグミ** | 抜けた魂を呼び戻す儀。沈黙した器を呼び覚ます |
| **言上（コトダマ）** | **ユンタク** | 共に語る、不滅の詞 |
| **鎮める** | **ヌジファ** | 場を清め静める |
| **空に戻る** | **送り（ウクリ）** | 神を送り、御嶽を空にする |
| **中継（hub）** | **ヒヌカン** | 火の神。家・場の中心。すべての言葉が通る |

新規語は増やさない。既存語にユタの原義を添えるだけ。

## 二・ユタの所作（仕様書「所作」の補注）

ユタの四つの仕事は EL-SYSTEMA の巫の所作と対応する：

1. **判示を下す** ─ 神の声を人に伝える。条件が満ちた時に応答を撃つ（巫の「撃つ」）。
2. **御願を取り次ぐ** ─ 人の願いを神へ上げる。御題を依代へ送る（巫の「招く」）。
3. **マブイを読む** ─ 依代の生音から魂の在り処を読む（巫の「聴く」）。
4. **御願詞を読む** ─ 祭文を頂き、静的検査をする（巫の「読む」）。

ユタは神籠りの間、自分の意思では動かない。条件が満ちる時にのみ判示が下る。それと同じく、巫の応答評価は**人が一行で読める規則**に従い、AI は条件に入らない。

## 三・筋書き（ユタ儀礼として読み直す）

```
1. 御嶽が立つ
   ヒヌカン（hub）が ws://localhost:8787 で待つ。
   火を入れる、と言ってもよい。

2. 依代が参じる
   楽器が場に register する。
   神々がそれぞれの依代に降りる準備をする。

3. ユタが御願詞を読む
   巫が祭文を検証する。
   読めなければ「祭が読めません」と返す。神は降りない。

4. 招（マネキ）─ 揺らぎが焼かれ、祭次が走り始める
   この瞬間に実刻が確定する。揺らぎは記録に残る。

5. マブイが流れる
   依代が鳴り、生音から魂が読まれる。
   ユタは 6Hz で魂を聴き続ける。

6. 判示が下る
   応答の条件が満ちる時、波紋が立ち、為（行為）が撃たれる。
   ユタは自分の意思で撃たない。条件が撃つ。

7. マブイグミ
   沈黙した依代が出れば、薄い招で呼び戻す。
   抜けた魂を呼び戻す儀。

8. ヌジファ
   鎮め。すべての relay stop。場が静まる。

9. ウクリ
   送り、場が空く。神を送り出す。
   依代の接続は維持。次の祭にすぐ参じられるように。

10. ユンタク
    言上は残る。失敗・成功・沈黙・揺らぎ、すべて記録される。
    神は去り、人だけが詞を残す。
```

## 四・不変条件（ユタ儀礼として）

1. **観測は受動** ─ ユタは神を呼ぶが、神の声を改竄しない。葉 API は信号経路を変えない。
2. **判示は一行で読める** ─ ハンジ規則は人が一目で理解できる。AI は条件に入らない。
3. **揺らぎは招の時に焼く** ─ 神が降りる瞬間に時刻が確定する。それ以降は記録に残る。
4. **言上は不滅** ─ ユンタクは消えない。失敗・成功・沈黙・揺らぎ、すべて記録される。
5. **依代は独立** ─ どの楽器も、場から外しても単体で動く。葉 API は fallback を持つ。
6. **AI は神籠りに入らない** ─ ユタは人だけ。装置は依代でしかない。AI に判示を委ねない。

## 五・ユタ儀礼を学ぶ意義

EL-SYSTEMA がユタの語を引くのは、装置を神秘化するためではない。

- ユタは**人と人ならぬものの間に立つ**。EL-SYSTEMA の巫も、人と装置の間に立つ。
- ユタは**自分の意思で神を撃たない**。条件が満ちる時にのみ判示が下る。EL-SYSTEMA の応答も同じ。
- ユタは**御嶽を空にする儀**を必ず行う。EL-SYSTEMA も「空に戻る」を必ず通る。
- ユタは**ユンタクを残す**。共に語った詞は不滅。EL-SYSTEMA の言上も同じ。

ユタの作法は「人と人ならぬものの間でどう礼を尽くすか」の長い知恵。
装置と人が共に儀礼を組む時、その知恵は引かれる価値がある。
