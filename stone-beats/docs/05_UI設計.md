# 05 UI 設計仕様書 ─ 自動演奏中の操作

## 一・設計原則

**ユタは作曲しない、媒介する**。
自動演奏中（祭中）の UI は、ユーザーが**演奏の中身を書き換える**のではなく、**儀礼を見守り・調律し・必要なら割って入る**ためにある。

四層構造：**見守る／調律する／割って入る／記す**。

---

## 二・場 ─ ユタの祭壇（[field/index.html](../field/index.html) 画面）

### A. 見守る（受動・常時表示）

| 部品 | 内容 | 現状 |
|---|---|---|
| **節の庭** | 鳴っている依代を点で、沈黙は薄く、波紋は瞬間に重ねる | [field/index.html](../field/index.html) に canvas あり ─ そのまま使う |
| **マブイ計** | 各依代の `presence` / `low` / `high` を 6Hz で表示（線または棒） | **要追加**（kehai は配線済み） |
| **祭次の現在地** | 今何番目の御願が走っているか、次は何秒後か | **要追加** |
| **判示の盤** | 応答規則の一覧、各規則の「条件が満ちつつあるか」を色で示す | **要追加** |
| **ユンタクの河** | 言上が流れる時系列のテキスト窓 | **要追加** |
| **時計** | 招からの経過、祭の長さ全体に対する位置 | **要追加** |

### B. 調律する（能動・破壊しない）

ユタは依代の音色を直接弄らない。**儀礼の流れに歪みを与える**ことだけする。

| 部品 | 役 | 値域 |
|---|---|---|
| **出力** | マスター減衰 | 0-100 |
| **時間倍率** | 祭次を遅らせる／早める（揺らぎはそのまま） | 0.5x - 2.0x |
| **天気逸れ** | 全体に乗る一様な調律（湿り・乾き・冷え・熱り） | 4 状態 |
| **マブイの厚さ** | 全依代の `kehai` 報告閾値を底上げ／削る | -50 +50 |

**個別の楽器パラメータには触らない**。器の中に入って弄るのは「祭の途中で作曲する」こと。儀礼の作法に反する。

### C. 割って入る（祭の流れを壊す権限）

非常時のみ。ボタンは大きく、視覚的に区別する（赤系統）。

| 部品 | 為 |
|---|---|
| **マブイグミ** | 沈黙した依代を一括で呼び戻す（短い招を撃つ） |
| **判示の早撃ち** | 条件が満ちつつある応答を**今すぐ**撃つ |
| **判示の見送り** | 次に発火する応答を一度だけ見送る |
| **招き直し** | 祭次を冒頭に戻し、招をやり直す（言上は残る） |
| **ヌジファ** | 全停止、ramp を 2 秒で 0 へ |
| **ウクリ** | 場を空にする（依代の接続は維持） |

### D. 記す（人の詞を流す）

| 部品 | 役 |
|---|---|
| **ユンタク入力** | 人が一行を打ち込むと、言上に追記される。AI は読まないが、人は読む |
| **しるし** | 「今この瞬間」を強調するマーク（時計と紐付き）。後で振り返る時の旗 |
| **書き出し** | 言上を JSONL で保存。session 単位 |

## 三・器側 ─ 自動演奏中の見え方

各楽器（[stone-beats.html](../stone-beats.html) / [ocean.html](../ocean.html) / その他）には**遠隔操作のしるし**が要る：

| 部品 | 役 |
|---|---|
| **接続灯** | 場に繋がっているか（緑＝繋ぎ、灰＝独立、赤＝切断） |
| **御願の到来** | 巫から御題が来た瞬間、画面の縁が薄く光る |
| **判示の発火** | 自分が応答の対象になった時、波紋が広がる |

楽器の音色 UI は**演奏中もそのまま操作できる**。ユーザーが「祭の最中に魂を弄っている」ことは儀礼上ありえる ─ ユタ自身が依代に憑く時もある。ただし操作の事実は言上に残る（後で読み返せる）。

## 四・自動演奏中に操作するべきもの ─ 一覧

ユーザーの目線で、祭中に「操作できる／したい／してよい」もの：

### 必須（祭の質を決める）
- **出力**（マスター音量）
- **時間倍率**（早回し／緩める）
- **ヌジファ**（緊急停止）
- **ウクリ**（場を空に）

### 推奨（祭の表情を変える）
- **天気逸れ**（湿り・乾き・冷え・熱り）
- **マブイの厚さ**（依代の声をどれだけ拾うか）
- **マブイグミ**（沈黙呼び戻し）
- **判示の早撃ち / 見送り**

### 任意（祭の記録に印を打つ）
- **ユンタク入力**（人の詞を流す）
- **しるし**（瞬間に旗を立てる）
- **書き出し**（session を保存）

### 演奏内（音色の世界に入る、儀礼から逸れる）
- **個別楽器のパラメータ直接操作**（stone-beats / ocean それぞれのスライダ群）
- これは儀礼上は逸れだが、ユタが依代に憑く時もある ─ 禁じない、ただし**操作は言上に記録される**

## 五・UI レイアウト（粗案）

[field/index.html](../field/index.html) の右上に「節の庭」、左下に「祭次の現在地」と「判示の盤」、中央下に「ユンタクの河」、右下に **A 層**（見守り）、左上に祭の制御ボタン群（**B/C 層**）。下端に**しるし**と**ユンタク入力**。

```
┌──────────────────────────────────────────────────┐
│ [接続灯] EL-SYSTEMA ─ ヲサの場                    │
│ [祭文を読む]  [祭を始める]  [ヌジファ]  [ウクリ]   │ ← C 層（破壊権）
├──────────────────────────────────────────────────┤
│                                                    │
│         節 の 庭（canvas）                         │
│                                                    │
│  ・ 玄武岩  ・ 砂礫  ・ 深海  ・ 沖  ・ 海岸 …    │
│                                                    │
├─────────────────────┬────────────────────────────┤
│  祭次の現在地        │  マブイ計（依代別の魂線）   │ ← A 層（見守り）
│  3/12 ─ +0:24 まで   │  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─    │
│                      │                              │
│  判示の盤            │  時間倍率 [1.0x]            │ ← B 層（調律）
│  ▸ 格子満ち...      │  天気逸れ [湿り]             │
│  ▸ 沈黙呼び戻し...  │  マブイの厚さ [+0]           │
├─────────────────────┴────────────────────────────┤
│  ユ ン タ ク の 河（時系列のテキスト）             │ ← D 層（記す）
│  > 招、20:14:33                                    │
│  > 判示「格子が満ちた」、20:15:02                  │
│  > [人] ここから海が深くなる、20:15:30             │
├──────────────────────────────────────────────────┤
│  [人] ___________________ [しるし]  [書き出し]    │
└──────────────────────────────────────────────────┘
```

各部の色彩は既存 [field/field.css](../field/field.css) の系統に合わせる。B 層・D 層は淡く、C 層は赤系で強く区別する。
