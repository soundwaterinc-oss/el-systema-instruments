# 09 接続契約 ─ 依代を場に上げる時の最小契約

各依代（楽器）が場（ヒヌカン＝hub）と繋がる時に守るべき**最小契約**。Cline はこれを写経することで、どの楽器も同じ作法で場に上がる。
contract を破ったら場に上げない（[02_仕様書要約.md](02_仕様書要約.md) §四・不変条件）。

---

## 一・物の置き方

依代のリポジトリに以下の三本を**コピーで配置**する：

```
<repo-root>/
└ shared/
    ├ el-systema-shapes.js
    ├ el-systema-transport.js
    └ el-systema-control.js
```

これらは [el-systema-acid/shared/](../shared/) を**正典**とする。バージョンが新しくなったら写し直す。
（理由：依代は単体動作も保証する。CDN を中継すると単体起動が不安定になる）

---

## 二・index.html の修正

依代の main script タグの**直前**に三本を `<script>` 形式で読む：

```html
<!-- 葉：場と繋ぐための三本。読み込めない／繋がない時は下の fallback で単体動作 -->
<script src="shared/el-systema-shapes.js"></script>
<script src="shared/el-systema-transport.js"></script>
<script src="shared/el-systema-control.js"></script>

<script>
  // 既存の依代スクリプト ...
</script>
```

順序は **shapes → transport → control**（依存順）。

## 三・葉 API の呼び出し

依代側スクリプトの**冒頭**に fallback を置く：

```js
if (typeof window.registerElSystemaInstrument !== "function") {
  window.registerElSystemaInstrument = function(){};   // 場に繋がない時の no-op
}
```

そしてオーディオ初期化が完了した時点で `registerElSystemaInstrument({...})` を一回呼ぶ。
呼ぶタイミングは「`AudioContext` と `masterBus`（出力 GainNode）が在ること」が条件。

```js
registerElSystemaInstrument({
  id: "<unique-id>",                  // 必須・場で一意
  audioContext: <AudioContext>,        // 必須・kehai 観測用
  outputNode: <GainNode (masterBus)>,  // 必須・kehai 観測の挿し口（destination では無く master 段）

  // ─ 御題ハンドラ（巫から飛んで来る相）。on* と bare 形式どちらでも可 ─
  play:       () => { /* 既存「鳴らす」相当 */ },
  stop:       () => { /* 既存「止む」相当 */ },
  setParam:   (name, value) => { /* 既存 UI の同名パラメータを反映 */ },
  ramp:       (name, from, to, durationSec) => { /* rAF で滑らかに */ },
  loadPreset: (preset) => { /* preset object を一括反映 */ },
  snapshot:   () => ({ /* 主要パラメータを object で返す */ }),
});
```

### `id` の命名規則

- 場で**一意**
- ローマ字小文字＋ハイフン（例: `stone-beats`、`ocean`、`geometry-scanner`）
- 短く、意味が読める

### `outputNode` の選び方

- `destination` ではなく **master 段（user volume が掛かる手前の GainNode）**を渡す
- 葉 API は内部で `AnalyserNode` を一本足して観測する。**信号経路は変えない**
- 既存 `analyser` がある場合は `sharedAnalyser:` に渡す（重複を避ける）

### `setParam` の最小契約

| 守る | 守らない時 |
|---|---|
| 同名 UI パラメータの値を反映する | UI と内部値が乖離する |
| **値が範囲外なら clamp**（throw しない） | 場のメッセージで楽器が落ちる |
| ドット表記（例: `"voice.玄武岩.bpm"`）を受け取れる場合は処理する | 場から細かい制御ができない |
| 同値の再代入は no-op で良い | 余計な ramp や音の途切れが起きる |

### `ramp` の最小契約

| 守る | 守らない時 |
|---|---|
| rAF（requestAnimationFrame）で滑らかに値を動かす | 階段状になり、可聴ノイズが出る |
| **同パラメータへの新しい ramp が来たら前のをキャンセル**（後勝ち） | 二つの ramp が競合して暴れる |
| `duration <= 0` の時は即座に `to` をセット | 不定動作 |

### `loadPreset` の最小契約

| 守る | 守らない時 |
|---|---|
| `preset` object のキーを既知のものに限定して反映 | 未知キーで落ちる |
| 既知キーで値が無効なら**そのキーだけスキップ** | 一つ失敗すると全部反映されない |

### `snapshot` の最小契約

| 守る | 守らない時 |
|---|---|
| **JSON シリアライズ可能なフラットな object** を返す | 巫側で `JSON.stringify` できず言上に残らない |
| 関数や循環参照を含めない | 同上 |

## 四・視覚のしるし（楽器側 UI）

[05_UI設計.md](05_UI設計.md) §三 に従う：

| 部品 | 表示位置 | 状態 |
|---|---|---|
| **接続灯** | 画面右下隅 / 既存のロゴ脇 | 緑＝繋ぎ、灰＝独立、赤＝切断 |
| **御願の到来** | 全画面の縁を 1 フレーム薄く光らせる | 御題受信時 |
| **判示の発火** | canvas 中央から外向きに波紋 | 自分が応答対象になった時 |

## 五・合格判定（接続が通ったか）

依代が場と繋がっている、と判定する条件：

1. `http://localhost:<port>/<instrument>.html` を開くと**接続灯が緑**になる
2. 巫の「節の庭」にその依代の節が現れる
3. `field/` から `play` を送ると依代が鳴る
4. `setParam` で巫から弄ったパラメータが楽器の UI に反映される
5. 鳴り終わった後、**沈黙が宣られる**（log に `silence` メッセージが現れる）

5 件すべて満たして合格。

## 六の二・音楽アダプタ（依代別 native マッピング）

[docs/12_音楽的整合.md](12_音楽的整合.md) §三 で立てた 12 canonical mode を、各依代が native param にどう翻訳するかの正典。M5 以降で各依代の `applyMusic({key, mode, bpm, register})` がこの表に従う。

`✓` = native に完全一致、`≈` = 方言として近似（依代がその伝統に最も近い己の声で応える）。

### stone-beats（音楽アダプタ）
- **受容**: `bpm` のみ（scale は持たない）
- **mode → native**: 全 mode で同一処理。`mode === "凪"` の時のみ `voices.*.on` を `砂礫` だけに絞る極小モード
- **root 符号**: 無
- **tempoRatio 既定**: 1（M5）。M6 で動境地・嵐境地で 2
- **modulation policy 既定**: immediate
- **register zone**: hi

### ocean（音楽アダプタ）
- **受容**: `key`, `mode`
- **mode → native scale**:
  - 凪 → `ペンタトニック` + `kg.level=0` `oki.level=0`（5 度だけ残す）
  - 琉球 → `ペンタトニック` ≈
  - 平調子 → `ヒラジョシ` ✓
  - 陰旋 → `ヨナ抜き` ≈
  - アイヌ → `ヨナ抜き` ≈
  - シベリア → `リディアン` ≈
  - モンゴル → `ペンタトニック` ✓
  - スレンドロ → `Whole Tone` ≈
  - ペログ → `ヒラジョシ` ≈
  - マカーム → `リディアン` ≈
  - バイラヴィ → `ヨナ抜き` ≈
  - 無 → `Whole Tone` ≈
- **root 符号**: Hz、`OCEAN_ROOTS = [55,65,73,82,87,98,110,123,138]` から `nearestOceanRoot(key)` で最近接を選ぶ
- **tempoRatio 既定**: 1/2（drift = bpm × 0.5）
- **modulation policy 既定**: voice-led
- **register zone**: bass

### geometry-scanner（音楽アダプタ）
- **受容**: `key`, `mode`, `bpm`
- **mode → native scale**:
  - 凪 → `Pentatonic Bloom` + `bassLevel` のみ active
  - 琉球 → `Pentatonic Bloom` ≈
  - 平調子 → `Japanese In` ≈
  - 陰旋 → `Moss Minor` ≈
  - アイヌ → `Moss Minor` ≈
  - シベリア → `1/f Harmonic` ≈
  - モンゴル → `Pentatonic Bloom` ✓
  - スレンドロ → `Pentatonic Bloom` ≈
  - ペログ → `Japanese In` ≈
  - マカーム → `Cellular Major` ≈
  - バイラヴィ → `Moss Minor` ≈
  - 無 → `1/f Harmonic` ≈
- **root 符号**: 文字、`GEOMETRY_ROOTS = ["C","D","Eb","F","G","A","Bb"]` から clamp（[0,2,3,5,7,9,10] のうち最近接）
- **tempoRatio 既定**: 1。M6 で動境地で 3/2
- **modulation policy 既定**: phrase-aligned
- **register zone**: hi

### particle-noise（音楽アダプタ）
- **受容**: `bpm` のみ（scale は持たない）
- **mode → native**: `mode === "凪"` の時のみ density と rate を極小に。他 mode では無視
- **root 符号**: 無
- **tempoRatio 既定**: rate = bpm/60 × 4（M5 では 1 として、`rate` には bpm/60 を入れる）
- **modulation policy 既定**: immediate
- **register zone**: hi

### kagome-sound（音楽アダプタ）
- **受容**: `key`, `mode`, `bpm`
- **mode → native scalePreset**:
  - 凪 → `scaleCategory=custom`, `customScale = [root, root×1.5]`（5 度のみ）
  - 琉球 → `scaleCategory=japanese`, `scalePreset=ryukyu` ✓
  - 平調子 → `scaleCategory=japanese`, `scalePreset=hirajoshi` ✓
  - 陰旋 → `scaleCategory=japanese`, `scalePreset=insen` ✓
  - アイヌ → `scaleCategory=japanese`, `scalePreset=insen` ≈（M5 暫定、M7 で custom Hz 四度堆積に差替え予定）
  - シベリア → `scaleCategory=generative`, `scalePreset=harmonic_series` ✓
  - モンゴル → `scaleCategory=japanese`, `scalePreset=yo` ✓ または `world/pentatonic_major` ✓
  - スレンドロ → `scaleCategory=world`, `scalePreset=slendro` ✓
  - ペログ → `scaleCategory=world`, `scalePreset=pelog_5` ✓
  - マカーム → `scaleCategory=world`, `scalePreset=maqam_rast` ✓
  - バイラヴィ → `scaleCategory=world`, `scalePreset=bhairavi` ✓
  - 無 → `scaleCategory=generative`, `scalePreset=chromatic` ✓
- **root 符号**: 無（scale 内に root が埋め込まれる）。`key != C` の時は M7 で動的 customScale 生成。M5 では native preset のみ使う（root は C4 固定）
- **tempoRatio 既定**: 1。M6 で流境地で 2/3
- **modulation policy 既定**: phrase-aligned
- **register zone**: mid

### mycorrhiza-beat（音楽アダプタ）
- **受容**: `bpm` のみ（scale は持たない）
- **mode → native**: `mode === "凪"` の時のみ `sendLevel.*` 全部を半減
- **root 符号**: 無
- **tempoRatio 既定**: 1（master 拍の基準）
- **modulation policy 既定**: immediate
- **register zone**: hi（実体は mid 寄り）

### moss-reservoir（音楽アダプタ）
- **受容**: `key`, `mode`, `bpm`
- **mode → native**: scale 概念は無いが、`rootHz` で root を反映。`mode === "凪"` の時のみ `den` を極小に
- **root 符号**: Hz、`keyToHz(key, 1)`（C1=32.70 Hz）の範囲（24-108 Hz に clamp）
- **tempoRatio 既定**: 1/2
- **modulation policy 既定**: voice-led
- **register zone**: bass

### planarian-drone（音楽アダプタ）
- **受容**: `key`, `mode`
- **mode → native targetScale**:
  - 凪 → `pentatonic` + `layer.0` のみ active
  - 琉球 → `mixolydian` ≈
  - 平調子 → `hirajoshi` ✓
  - 陰旋 → `minor-pent` ≈
  - アイヌ → `minor-pent` ≈
  - シベリア → `harmonic` ≈
  - モンゴル → `pentatonic` ✓
  - スレンドロ → `pentatonic` ≈
  - ペログ → `hirajoshi` ≈
  - マカーム → `dorian` ≈
  - バイラヴィ → `minor-pent` ≈
  - 無 → `harmonic` ≈
- **root 符号**: 半音 index、`PLANARIAN_ROOTS = [0,2,4,5,7,9,11]` から clamp
- **tempoRatio 既定**: ─（拍を持たない）
- **modulation policy 既定**: voice-led
- **register zone**: mid

### cell-noise（音楽アダプタ）
- **受容**: `key`, `mode`
- **mode → native**: scale 概念は無いが、`pitchBase` で root を反映。`mode === "凪"` の時のみ `pulseRate` を 0.5 に・`burstDensity` を 0.1 に（極小モード）
- **root 符号**: Hz、`keyToHz(key, 4)`（C4=261.63 Hz）
- **tempoRatio 既定**: 1/8（sub-harmonic pulse）
- **modulation policy 既定**: section-aligned
- **register zone**: hi

### 共通仕様

- **applyMusic は冪等**: 同じ music 状態で何度呼ばれても同じ relay を返す
- **未知 mode**: warn を言上に出して無視（runtime には来ないが防御的に）
- **clamp ずれ**: planarian / geometry が key を最近接にずらすのは方言の一部、警告不要
- **scale を持たぬ依代**: `mode === "凪"` だけ特別扱い、他 mode は無視
- **合格判定追加**：[§五](#五合格判定接続が通ったか) に二点：
  - 場から `music.key = "F"` を送ると、scale を持つ依代の root が **4 秒以内に** F 相当に到達する
  - `music.bpm = 120` を送ると、依代の native bpm が `120 × tempoRatio` に再設定される

## 七・破ってはいけないこと

1. **信号経路を変えない** ─ AnalyserNode は分岐で挿す、master の前後を切り替えない
2. **既存 UI を壊さない** ─ 場と繋がない時も独立して動く
3. **id を勝手に変えない** ─ 場に既に立っている依代の id は不動
4. **`audioContext` を持ち回らない** ─ 葉 API はパッシブ。`ac.suspend()` を勝手にしない

