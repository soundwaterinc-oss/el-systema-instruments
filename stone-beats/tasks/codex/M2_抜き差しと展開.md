### 2. 各 tick での発火ロジック

`field/nagare.js` の中で：

```js
function nagareTick() {
  if (!NAGARE.state.runningSince) return;

  const mode = ElSystemaModes[NAGARE.config.境地];

  // 拍：律動を駆動（毎 167ms ≒ 6Hz）
  for (const id of NAGARE.state.activeInstruments) {
    const map = ElSystemaInstrumentMap[id];
    if (map && map.律動) {
      const v = Natural[mode.拍.fn].next(NAGARE.fnState.拍[id]);
      const smoothed = smooth(v, mode.拍.smooth, NAGARE.lastValues.拍[id] || v);
      NAGARE.lastValues.拍[id] = smoothed;
      const relay = map.律動.apply(id, smoothed);
      sendRelay(relay);
    }
  }

  // 節：抜き差しを駆動（毎 10 秒）
  if (Date.now() - NAGARE.last節At > 10000) {
    NAGARE.last節At = Date.now();
    for (const id of NAGARE.state.activeInstruments) {
      const map = ElSystemaInstrumentMap[id];
      if (map && map.抜き差し) {
        for (const voice of map.抜き差し.voices) {
          const v = Natural[mode.節.fn].next(NAGARE.fnState.節[`${id}.${voice}`]);
          const smoothed = smooth(v, mode.節.smooth, ...);
          const relay = map.抜き差し.apply(id, voice, smoothed);
          sendRelay(relay);
        }
      }
    }
  }

  // 章：転調（毎 90 秒）
  if (Date.now() - NAGARE.last章At > 90000) {
    NAGARE.last章At = Date.now();
    for (const id of NAGARE.state.activeInstruments) {
      const map = ElSystemaInstrumentMap[id];
      if (map && map.転調) {
        const v = Natural[mode.章.fn].next(NAGARE.fnState.章[id]);
        const relay = map.転調.apply(id, v);
        sendRelay(relay);
      }
    }
  }

  // 巻：境地遷移（毎 5 分、巫の意志を尊重するので自動切替は任意）
  // 自動境地遷移は M3 で OFF/ON 選択できるよう
}
```

### 3. smoothing 実装

```js
function smooth(target, alpha, prev) {
  // alpha = 0 → 二値（target そのまま）
  // alpha = 1 → 全く動かない
  // 通常は 0.3..0.7
  if (alpha === 0) return target > 0.5 ? 1 : 0;
  return prev * alpha + target * (1 - alpha);
}
```

### 4. 二値モード（整・Ikeda 様）

`smooth=0` の時は target > 0.5 ? 1 : 0 にする（前述）。
さらに transition を**拍グリッドに quantize** して綺麗に：

```js
if (mode.拍.smooth === 0) {

}
```

### 5. 「依代別 on/off」管理

巫が「この依代は NAGARE の対象に入れる／外す」を選べる：

```js
NAGARE.config.依代別 = {
  "stone-beats":     { 抜き差し:true, 律動:true,  転調:false },
  "ocean":           { 抜き差し:true, 律動:false, 転調:true  },
  // ...
};
```

UI は M3 で。

## 合格条件

1. NAGARE.start(seed) で境地 "流" を選び 30 秒走らせると、stone-beats の voice 別 volume が「流れるように」上下する
2. 境地 "整" を選ぶと、voice の on/off が **二値で** quantize されて切り替わる（Ikeda 様）
3. 境地 "嵐" だと **激しく予測不能** に切替が起きる
4. ocean が NAGARE 対象の時、章境界で root が変化（音階の進行）
5. NAGARE 駆動の relay が言上に残る
6. 依代別 on/off を変えると即座に反映（指定 OFF の依代は NAGARE が触らない）

## 触ってはいけないもの
- 依代側のコード（葉 API 経由 setParam だけ）
- ramp の互換性（[C3_ramp堅化](C3_ramp堅化.md)）

## 注意
- 6 依代 × 6 voice × 6Hz = 216 relay/sec ─ hub は捌けるが、relay が増えすぎないよう **smoothing で値が変わった時だけ送る**等の最適化を検討
- ocean の root 急激変化は耳に痛い ─ 章境界では **ramp 経由**で 2-3 秒掛けて遷移するのが品があって良い
- 抜き差しが**全 voice 一斉に OFF** になると沈黙が起きる → 沈黙判定が誤発火する可能性。 NAGARE は最低 1 voice を rotation で保つ「土台」を入れる方が安定
- マッピングが未定義の依代は **skip**（落とさない）
