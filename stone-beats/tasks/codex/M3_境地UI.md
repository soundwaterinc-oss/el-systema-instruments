### 部品仕様

#### 境地セレクタ
- `<select>` で 6 種（凪 / 流 / 動 / 嵐 / 整 / 無）
- 選択即時で NAGARE.setMode(name) を呼ぶ
- 変更すると時間スケール別の関数欄が**境地のプリセットで上書き**される
- ユーザが個別に関数を弄ったあと境地を変えると、ユーザの設定が消える ─ 確認なし（境地が支配的）

#### 流れを起こす / 鎮める
- 招の時に NAGARE.start(seed) を呼ぶか「流れを起こす」で別に起こすかは UI 選択
- 既定：招と一緒に NAGARE も起きる（チェックボックスで「招と同時に起こす」）
- 「流れを鎮める」は祭次・判示はそのまま、NAGARE のみ止む

#### seed 欄
- 数値入力（0..1 の小数）または空欄なら自動焼き
- 「焼き直す」ボタンで現在の seed を保ったまま NAGARE をリスタート
- 言上に seed が必ず記録される

#### 時間スケール別の関数欄
- 各階（拍／節／章／巻）に：
  - 関数セレクタ（9 種）
  - smoothing スライダ（0.0 .. 1.0）
- 「境地が変わると上書きされる」旨を小さく注記

#### 依代別チェック
- 接続済みの依代を自動で列挙（[field/field.js](../../field/field.js) の `state.instruments`）
- 各依代に「抜き差し」「律動」「転調」の三チェック
- 依代が持っていない機能（[docs/09_接続契約.md §六](../../docs/09_接続契約.md) でマッピング無いもの）はチェックボックスを disable

### 反映の即時性

すべての操作は**即時**反映：
- 境地切替 → 1 拍以内に流れが変わる
- 関数変更 → 次の tick から新関数
- smoothing → 次の値計算から
- 依代別チェック → 次の tick から対象が変わる

### CSS

[field/field.css](../../field/field.css) の系統に合わせる。
- 「流れ」と「境地」の見出しは [05_UI設計.md §五](../../docs/05_UI設計.md) のレイアウト案を踏襲
- 6 境地を色分けしたい場合：凪=青、流=緑、動=黄、嵐=赤、整=白、無=黒

### names.js への追記（部分）

[field/names.js](../../field/names.js) に既に `境地` キーが定義されている（M1 で追加された前提）。UI ラベルもここから引く。

```js
UI: {
  ...,
  nagare: "流れ",
  kyouchi: "境地",
  nagareStart: "流れを起こす",
  nagareStop:  "流れを鎮める",
  seedLabel:   "seed",
  seedRefresh: "焼き直す",
  時間スケール: { 拍:"拍", 節:"節", 章:"章", 巻:"巻" },
}
```

## 合格条件

1. 「流れを起こす」を押すと NAGARE が起動、節の庭の動きが変わる
2. 境地セレクタで 6 種を順に切り替え、各境地で**性格の違い**が音と動きで分かる
3. 時間スケール別の関数を切り替えて、即座に流れが変わる
4. 依代別チェックを外すと、その依代は NAGARE が触らなくなる
5. 「流れを鎮める」で NAGARE が止む（祭次は走り続ける）
6. seed が言上に残る
7. 既存の B/C/D 層（調律・破壊権・記す）と共存する（UI が崩れない）

## 触ってはいけないもの
- 既存の A 層（節の庭・マブイ計など）
- 既存の祭次・判示の操作
- メッセージ schema

## 注意
- 境地切替は**頻繁に押されることがある** ─ debounce 不要、即時で良い（NAGARE 側で次 tick を待つ）
- seed 欄は任意 ─ 空ならランダム、入れれば決定論
- 「依代別チェック」は接続のある依代のみ列挙、切れた依代は薄く表示
- DJ 卓的に見せたいが**色を派手にしすぎない** ─ 既存 [field/field.css](../../field/field.css) の落ち着いた系統を守る
